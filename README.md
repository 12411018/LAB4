# LAB4 — VIT Semester Result Calculator

A responsive React website for viewing and calculating a VIT student's semester result across four subjects.

## Features

- Enter MSE marks (out of 30) and ESE marks (out of 70) for each subject.
- Automatically calculates subject totals, semester total, and overall average.
- Export the result as a CSV file or reset marks to the sample values.
- Responsive layout for desktop and mobile screens.

The page displays student details for **Nikhil Nikalje (PRN: 422604)**. The included subjects and marks are sample data and can be edited in the interface.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
